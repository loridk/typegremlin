Your snippets stay yours

TypeGremlin stores snippets locally using Chrome extension storage. It has no account, analytics, advertising, tracking, external API, or remote service. Shortcut matching happens locally in your browser.

Current support

TypeGremlin currently supports standard inputs and textareas in Chrome. Contenteditable regions and rich-text editors are not yet supported. It is not a password manager and should not be used to store authentication secrets.
