TypeGremlin Privacy Policy

Last updated: August 24, 2026

Summary

TypeGremlin does not collect, transmit, sell, or share user data. Saved snippets and text-expansion processing remain local to your device and are never sent to the developer or an external service.

Information Stored Locally

TypeGremlin stores the shortcuts and replacement text you create using chrome.storage.local, Chrome's extension-specific local storage.

Saved snippets remain on your device until you delete them, replace them by importing a backup, or uninstall TypeGremlin. Uninstalling the extension removes its local storage.

Chrome's local extension storage is not an encrypted password vault. TypeGremlin is not a password manager, and you should not use snippets to store passwords, authentication codes, financial information, or other highly sensitive secrets.

Text Processing

To provide text expansion, TypeGremlin responds when you type in supported standard text inputs and textareas. It examines the text immediately before the cursor to determine whether it ends with one of your saved shortcuts.

This processing occurs locally in your browser. TypeGremlin does not save ordinary typed content, create a typing history, or transmit typed content to the developer or another service.

Sensitive Fields

TypeGremlin is designed to avoid text expansion in fields identified as password-related. It checks signals including password input types, password autocomplete values, and password-related field names or identifiers.

Website markup varies, so this protection should not be treated as a substitute for careful handling of sensitive information. TypeGremlin should not be used to store or enter passwords or other authentication secrets.

Website Access

TypeGremlin runs on regular webpages so it can expand shortcuts wherever you choose to type. This requires broad website access in Chrome.

TypeGremlin uses this access only to detect saved shortcuts in supported editable fields and insert the corresponding locally stored replacement text. It does not collect browsing history, website addresses, cookies, page contents, or information from fields where expansion is not being performed.

Backup and Restore

TypeGremlin can export saved snippets as a JSON backup file. The exported file is created locally and downloaded through normal browser behavior. TypeGremlin does not upload or transmit the backup.

Import occurs only when you select a backup file. The file is read and validated locally before you confirm replacing the snippets stored on your device.

Backup files contain the shortcut and replacement text you created. You are responsible for storing exported files securely and deleting them when they are no longer needed.

Network Requests and Tracking

TypeGremlin does not require an account, external API, or network request to provide text expansion, snippet management, backup, or restore features.

TypeGremlin does not include analytics, advertising, tracking technology, or third-party cookies.

Chrome Extension Permissions

TypeGremlin requests Chrome's storage permission to save snippets locally on your device.

Its content script runs on regular webpages so shortcuts can expand across supported sites. TypeGremlin does not request access to browser tabs, browsing history, cookies, the clipboard, downloads, or the network.

Limited Use

Information handled by TypeGremlin is used only to provide its text-expansion, snippet-management, backup, and restore features.

TypeGremlin complies with the Chrome Web Store User Data Policy, including its Limited Use requirements. Information is not transferred to third parties or used for advertising, lending, creditworthiness, or unrelated purposes.

Changes to This Policy

This policy may be updated if TypeGremlin's functionality or data practices change. The updated date at the top of this page identifies the latest revision.
